# Tactical Player Value Report: Spiritually Aligned Edition
Based on the 2025 H&A Season.

## Methodology: Edge-Engine Tactical Value Added (TVA)
This report uses the **exact same exponential decay mathematics** as the team Matchup Engine (engine_core.py).
In the main engine, a score is worth 1.0 point, the action before it is worth 0.9 points, the action before that 0.81 points, etc.

For this player report:
1. We mapped every player possession to the A1-E3 grid.
2. We calculated the League Average Expected Points (EV) for simply touching the ball in each grid.
3. We calculated the actual Exponential Decay Points the player generated on that specific chain.
4. **Tactical Value Added (TVA) = Actual Points - Expected Points**

This means players are rewarded most heavily for initiating long, sweeping chains from deep defense (A1/A2) that ultimately result in a score, because they earn 0.65 points on an action that historically expects only 0.05 points.
It perfectly isolates players who break the engine's baseline expectations.
